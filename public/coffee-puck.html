3D coffee puck

The same extraction model on the close-packed lattice the 2D lab is a slice of. Impermeable grains should still conduct past the 2D cliff.

Built with the published npm package @hexlife/embed@1.13.4 <hexlife-hcp> · jsDelivr import map · no build step

Site percolation on the triangular lattice has pc = 1/2, so the 2D six-state lab goes silent near packing 0.50. HCP site pc is about 0.20. An impermeable-grain bed should still deliver to the cup at packings 0.50–0.75. Dual-porosity still has a job at real ~0.90 packings.

The engine is general: a 12-neighbour conservative 3D CA. Coffee is a k⁴ table a host installs. Gravity is slot 3 of every tet — the unique lowest site. Drag to orbit, scroll to dolly, drop the opacity to see grains behind grains, or pull the clip plane to cut a slab. Uncheck auto-rotate to hold the camera still.
